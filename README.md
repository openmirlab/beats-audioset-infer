# beats-audioset-infer

Bidirectional Encoder representation from Audio Transformers (BEATs) is an audio representation model, not beat tracking. This standalone inference package exposes its AudioSet-fine-tuned 527-class scores and native encoder patch embeddings.

**Original research and implementation: [Microsoft BEATs](https://github.com/microsoft/unilm/tree/master/beats). All model credit belongs to the upstream authors.**

Implementation in progress. Code is MIT; checkpoint licensing is not explicitly stated. This repository remains private; weights are not bundled, rehosted, or publicly published.
